Установка

Три шага до игры

Установщик NSIS: можно выбрать папку и создать ярлык на рабочем столе.

01

Скачайте установщик

Возьмите последний .exe из блока «Скачать». Windows может показать предупреждение SmartScreen — нажмите «Подробнее» → «Выполнить в любом случае».

02

Установите и запустите

Выберите папку, дождитесь установки и откройте Y LaYncher. Отдельно ставить Java не обязательно — лаунчер сделает это сам.

03

Выберите версию и играйте

Добавьте аккаунт, выберите версию или модлоадер, нажмите «Играть». Прогресс установки и логи видны прямо в лаунчере.

Безопасность. Лаунчер не получает и не хранит пароль Microsoft: вход идёт через официальный OAuth Device Code Flow, а токены шифруются средствами ОС.

Вопросы

Коротко о главном

Это бесплатно?

Да. Y LaYncher распространяется бесплатно по лицензии MIT. Для игры нужна купленная Minecraft: Java Edition, если вы хотите заходить на лицензионные серверы; для одиночной игры и офлайн-серверов достаточно офлайн-аккаунта.

Нужно ли устанавливать Java отдельно?

Нет. Лаунчер ищет Java на компьютере, а если подходящей версии нет — скачивает официальную среду Mojang. Для старых версий нужна Java 8, для современных Forge/OptiFine — 17 или 21.

Куда скачиваются версии и миры?

По умолчанию в %APPDATA%\.minecraft. Папку можно изменить в настройках. Миры, моды и ресурспаки лежат в привычных папках saves, mods и resourcepacks.

Можно ли играть с модами?

Да. Установите Fabric, Forge или OptiFine, затем положите моды в папку mods — лаунчер умеет открывать её одной кнопкой. Менеджера модов внутри нет: это осознанно простая установка.

Почему Windows предупреждает при запуске?

Установщик не подписан платным сертификатом, поэтому SmartScreen может показать предупреждение. Файл можно проверить по контрольной сумме из GitHub Releases. Со временем репутация файла растёт.

Лаунчер связан с Mojang или Microsoft?

Нет. Это неофициальный проект сообщества. Minecraft, Mojang и Microsoft — товарные знаки соответствующих владельцев.
